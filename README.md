# 三角洲台钓助手

适用于 Windows 的简单台钓脚本，通过截图识别红绿漂尾、游戏提示、倒计时和血量，并发送鼠标及键盘操作。

## 安装与运行

需要 Windows、Python 3.10 或更高版本（包含 tkinter）。Python 依赖仅为 Pillow。

### PyCharm（推荐）

1. 用 PyCharm 打开本目录，选择 Python 3.10+ 项目解释器；可在 PyCharm 中创建虚拟环境。
2. 运行 `install.py`，依赖会安装到运行此脚本的解释器，并生成个人 `config.py`。已有配置不会被覆盖。
3. 手动进入游戏、装备入门台钓竿并面向可钓鱼水面。
4. 用同一解释器运行 `auto_fishing.py`，不需要启动参数。切回游戏后按 F6 绑定，再按 F8 开始。

运行 `observe.py` 进入只观察模式，不发送钓鱼输入；请先手动右键放大并稳定画面。

### 终端（可选）

```powershell
python install.py
python auto_fishing.py
# 仅观察
python observe.py
```

也可自行执行 `python -m pip install -r requirements.txt` 安装依赖。`install.py` 不会另建或切换解释器，因此安装与运行应使用同一个 Python 环境。

脚本不会启动游戏；需自行进入游戏并按快捷键绑定。

## 快捷键

| 按键 | 功能 |
|---|---|
| F6 | 绑定前台三角洲游戏窗口 |
| F7 | 暂停时框选漂尾或水花识别区域并保存配置 |
| F8 | 开始或暂停 |
| F9 | 退出并释放脚本按住的按键 |

切出绑定游戏窗口会自动暂停。开始前保持游戏在前台；F7 框选完成后需切回游戏再按 F8。

## 配置

首次运行会从 `config.example.py` 自动生成 `config.py`。也可手动复制后修改。配置文件每项有中文注释，修改后保存并重启脚本。

`config.py` 是个人配置，已通过 `.gitignore` 排除；共享默认值维护在 `config.example.py`。文件内容须为单个 `CONFIG = {...}` 字典，不支持执行 Python 语句。

| 参数 | 作用 |
|---|---|
| `right_press_delay` | 第二次左键后到按住右键的延迟，示例为 0.25 秒 |
| `cast_settle` + `zoom_settle` | 按住右键后等待再识别的总时间，示例为 2 + 1 秒 |
| `float_lock_frames` | 连续看到漂尾多少帧才锁定，示例为 3 帧 |
| `float_missing_frames` | 锁定后连续多少帧看不到漂尾才提竿，示例为 2 帧 |
| `bite_timeout` | 等待咬钩超时时间，示例为 25 秒 |
| `timer_alert_minutes` | 对局剩余时间提醒阈值，示例为 7 分钟 |
| `health_enabled` | 非满血提醒和下一轮按 X 的开关 |
| `health_x_hold` | 下一轮前按住 X 的时长，示例为 2 秒 |
| `state_enabled` | 右侧钓鱼状态提示识别开关 |

默认区域按 2560×1440 游戏客户区标定。不同分辨率下按客户区比例缩放；HUD 缩放或布局变化时需要重新校准。F7 只修改漂尾/水花框，时间、血量和操作提示区域须分别调整对应配置。

## 钓鱼流程

两次左键之间等待 `first_click_wait`；第二次左键后等待 `right_press_delay`，按住右键，再等待 `cast_settle + zoom_settle`，随后锁定漂尾并检测消失。确认咬钩后松右键，按配置完成提竿与后续点击，进入下一轮。

- 默认采用漂尾识别：先稳定锁定红绿漂尾，再连续确认其消失；未锁定时不会因空画面提竿。可将 `detection_mode` 改成 `splash` 使用保留的水花算法。
- “提竿过早”或“鱼已逃离”：确认后松键，等待 `failure_retry_wait` 再重抛。
- “背包已满”：仅记录提示，正常循环继续，暂不执行清包或暂停。
- 咬钩超时：松键并重开。新一轮若连续确认仍在钓鱼中，先按空格退出，确认抛竿界面后再开始；退出后无法确认界面则暂停。
- 等待期间若连续确认回到未抛竿界面则重开，避免将模式退出当成漂尾入水。

动画等待期间仍监测失败提示、倒计时和血量。

## 时间与血量提醒

时间识别结合数字模板、冒号定位与倒计时递减校验。首次需要连续三次且确实发生递减的读数；无法确认时跳过。每局在剩余时间达到阈值时提醒一次，确认新一局后重新允许提醒。阈值是游戏倒计时，不是脚本运行时长。

血量功能先确认 `/100` 界面，再判断血条是否满格，并非精确血量 OCR。连续确认非满血后播放提示音，在下一轮抛竿前长按 X；同一次持续非满血只处理一次。连续恢复满血会重新允许触发，并取消尚未执行的 X 操作。

## 文件与排错

- `auto_fishing.py`：自动钓鱼入口；`observe.py`：只观察入口。
- `install.py`：向当前解释器安装依赖并创建个人配置。
- `fishing.py`：窗口绑定、输入控制和钓鱼流程。
- `float_detector.py`、`failure_text.py`、`fishing_state.py`：漂尾、提示及模式识别。
- `timer_reader.py`、`countdown_alert.py`、`health_monitor.py`：时间与血量功能。
- `config_io.py`：读取和保存带注释配置。
- `assets/`：运行必需的模板与提示音，必须一起上传和下载。

运行时生成的诊断截图位于 `work/detection_debug/`，仅观察模式还会生成 `preview.png` 等文件，均已忽略提交。识别失败时可检查这些截图是否包含正确的 HUD 区域。
